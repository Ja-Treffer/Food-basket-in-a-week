# 07 · 术语表

看到对不上的词先来这里。左边是项目里的用法，右边是它在别处的常见含义 —— 有出入的标了 ⚠。

## 游戏内

| 词 | 本项目的意思 |
|---|---|
| **四本账** | 环境负荷 `p`、营养均衡 `s`、口味接受度 `c`、可用钱 `m`。四条 0–100 的相对刻度 |
| **读 数** | 上面四条里的任意一个数；不叫「分数」 |
| **环境负荷** `p` | 材料、运输、冷藏、丢掉份量的合成负担。**越低越好** |
| **可用钱** `m` | 省下来的钱。**越高越好**，但正数会引来后面的支出 |
| **崩盘** | 口味接受度跌破 25，家人出去补一顿；回吐最近 3 笔环境改善的 55% ⚠ 不是「游戏结束」 |
| **回弹 / rebound** | 省下的钱转投别处消费，把一部分环境收益抵消掉 |
| **延迟后果** | 早期选择在几天后追加的一笔 |
| **中期任务** | `LONG` 里的 L1–L6，单步；今天做，`after: 2~3` 天后到账 |
| **今日情景** | 每天先结算的一条外部事件（天气、促销、学校通知），不归因于玩家 |
| **结算日** | 一天结束时把当天所有选择摊开算账的那一刻 |
| **总结算** | 第七天结束后的四本账终值 + 逐日复盘 |
| **自定做法 / DIY** | 玩家自己写的一条做法，**不计入读数**，结账时标「需自行举证」 |

## 题库

| 词 | 意思 |
|---|---|
| **轻考核** | `review.html`，15 题库随机抽 6 题，每题 30 秒，共约 3 分钟 |
| **分组 A/B/C/D** | 配餐 / 采购 / 衣物 / 取舍；抽样时四组各至少一题 |
| **`a`** | 正确项下标（0–3） |
| **`x[i]`** | 「选了第 i 项错在哪」，正确项那格是空串 |
| **位置分布** | 正确项落在 A/B/C/D 的次数分布，用来防「三短一长选最长」 |

## 依据编号

| 前缀 | 指什么 |
|---|---|
| `H` | 卫生防护中心 / 营养资料（H1 均衡素食、H2 低脂烹调…） |
| `R` | 减排与行为研究（IPCC AR6、回弹、碳足迹批评…） |
| `F` | 材料与衣物生命周期 |
| `E` | 教育局课程文件 |
| `D` | 设计参数（D7 = 数值后置一类）⚠ 只在内部讨论用，不出现在学生卷面 |

## 工程词

| 词 | 意思 |
|---|---|
| **模板** | `src/game.template.html`，浏览器版的手改源 |
| **生成物** | `game.html`、`godot/data/game.json`、`godot/data/game-i18n.json` —— 别手改 |
| **词典** | `data/game-i18n.json`，567 条 `{zh, tw, en}`；`zh` 是匹配键 |
| **固定机位** | 舞台地面恒在 `y=104`，人物锚点 `x = 150 / 236`，换地点只换布景 |
| **黑幕** | 换场时那块 0.22 秒的全屏淡入淡出 |
| **抠底** | 把截图里背景去掉，留人物；本项目目前没做 |
| **自测** | `godot/tests/selftest.gd`，15 条断言 |
| **桩** | 给带 SSE 的页面注入一份假快照 `apply(snap)`，用来静态截图 |
