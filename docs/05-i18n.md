# 05 · 三语：怎么落、怎么维护

三种语言，顺序永远是 **`[简体, 繁體, English]`**，下标 `0 / 1 / 2`。

## 四个前端各自的机制

| 页面 | 文案存哪 | 取值方式 |
|---|---|---|
| `game.html` | 中文写在模板里；三语词典在 `data/game-i18n.json`，构建时内联进 `<script id="g18n">` | 运行时改写 `innerHTML` / `textContent` 的 setter，所有写入先过长词优先的替换 |
| `review.html` | 每题字段就是三元数组 `t/o/why/x` | `T(v)` 按 `LIDX` 取 |
| `live/host.html`、`live/play.html` | `UI` 表存界面词，题目来自 `quiz.json` 的三元数组 | `T()` + `F()`（占位符 `%a %b %n`） |
| `godot/` | 同 `game.html` 的词典，`I18nBox.t(s)` 查词 | 查不到就原样返回 |

### Godot 版的三个入口

| 位置 | 控件 | 连到哪 |
|---|---|---|
| **标题页最下面一行** | `简体 / 繁體 / EN` 三个按钮 | `TitleScreen.lang_picked` → `Presenter.set_lang()`，当场重灌标题、副标题、按钮、三条链接 |
| 右上纸板底部 | 同一个语言下拉 | `Hud.lang_changed` → `Presenter.set_lang()` |
| 资料面板 | 标题、段落、关闭按钮 | `Presenter._t()` 拼 body 时翻 |

语言**先选再开始**：标题页那行是玩家第一眼看到的东西；
进了游戏还能用右上角的下拉改，两处调用同一个 `set_lang()`。
`TitleScreen.apply_texts()` 只重写文字、不重建节点，所以切换时不会闪一下黑幕
（踩过：早先靠销毁重建，切一次语言标题页会跳一下）。

结算每一笔后面挂 `[依据 R5 / F1]`，编号本身不翻 —— 它是跨语言的通用标记。
点右上「资料」按编号查原文；H1 这类引用保持繁体原文不译，
面板顶部写清「摘录为原文或来源说明」，不让人把译文当原话。

## 语言入口

- 网址 `?lang=` 认：`0/1/2`、`zh|zh-hans|cn`、`tw|zh-tw|zh-hant`、`en`。
- `localStorage` 键：`cailan.review.lang` / `cailan.game.lang`。
- Godot：`--lang=0|1|2`，运行时用右上角下拉。

**踩过的坑**：`loadLang()` 最初只认 `tw/en/zh` 这类名字，而下拉提交的是 `"0"/"1"/"2"`，
于是 `?lang=2` 静默回落到简体 —— 数字分支必须显式写上。

## 词典维护规则

1. **`zh` 必须与页面上的中文字面量逐字一致**，包括全角标点、前后空格、`　`（全角空格缩进）。
2. 新增一句中文后，往 `data/game-i18n.json` 追加一条 `{zh, tw, en}` 即可；重复运行 patch 是幂等的。
3. 长的整句优先于短片段，所以「今日清单」和「今日」可以并存。
4. 依据编号（`H1` / `R5` / `F1`）**不翻译**，它是跨语言通用标记。
5. 繁体不是逐字替换表：`裡/里`、`著/着`、`臺/台` 要看语境，宁可整句重写。

## 三个真实翻车现场

### ① `en` 不能当反查源

`compile()` 原本三个语种都当源，结果一条 `en = " · "` 的词条把中文的 ` · ` 反查成了 ` 日 · `，
页面出现「今日清單 日 · 第 1 日 日」。
**修法**：只拿 `zh` 与 `tw` 当源（`for (i = 0; i < 2; i++)`）。

### ② `String.replace` 会吃掉 `$&`

patch 脚本用 `html.replace('<body>', '<body>\n' + block)` 注入，而 block 里 `esc()` 的替换串是 `'\\$&'`。
`$&` 在 replace 的**替换串**里有特殊含义（= 匹配到的内容），于是 `'\\$&'` 被替换成了 `'\\<body>'`，
转义全废、词典几乎不命中。
**修法**：用函数式替换 `html.replace('<body>', function () { return '<body>\n' + block; })`。

### ③ 桩快照要带 `deadline`

截 live 页面时把 `apply(<假快照>)` 注入到 `LIDX = loadLang(); applyLang();` **之后**，
否则 `applyLang()` 里的 `shownState = ''` 会和 render 顺序互相覆盖。
快照还必须带 `deadline: 0`，不然倒计时 tick 会把 `--` 覆盖成负数。
