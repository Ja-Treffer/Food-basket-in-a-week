# 01 · 项目是什么

## 一句话

给香港家政 / 科技与生活课堂用的一周情景模拟器：**一天两件事，做完才结账**；结账时四条读数（环境负荷、营养均衡、口味接受度、可用钱）互相拉扯，教的是「为什么这么做」和「冲突时先保哪一条」。

## 谁在用

- **学生**：一个人，或者一台电脑全班看投影。
- **老师**：10 分钟课堂里，7 分钟玩完一周，3 分钟用 `review.html` 对答案。
- **主持人**（可选）：用 `live/` 那套做现场抢答，全班手机作答。

## 一局怎么走

```
标题 → 第 1 日开场（今日情景）
     → 任务 A：NPC 开口 → 连续几步选择 → 每步 NPC 回一句为什么
     → 任务 B：同上
     → 入夜回厨房，灯下逐笔念账（每条后面跟一句 why）
     → 第 2 日 …… 第 7 日
     → 总结算：四本账 + 逐日复盘
```

- 第 1–3 日：每天两个普通任务（家里 / 街市 / 家政室 / 布店）。
- 第 4–5 日：一个普通任务 + 一个中期任务（今天做，两三天后才见效）。
- 第 6–7 日：两个中期任务。
- 14 个任务互不重复。

## 四条读数

| 代号 | 名字 | 方向 | 说人话 |
|---|---|---|---|
| `p` | 环境负荷 | 越低越好 | 材料、运输、冷藏、丢掉的份量 |
| `s` | 营养均衡 | 越高越好 | 蛋白质、铁、钙、B12 |
| `c` | 口味接受度 | 越高越好 | 跌破 25 家人会出去补一顿 |
| `m` | 可用钱 | 越高越好 | 省下来的钱会去别处花 |

选择阶段**一条数值都不显示**；只有结算时才动，并且每一笔都解释。这是刻意设计，理由见 [06-decisions.md](06-decisions.md)。

## 三条边界（别越过去）

1. **不是评分工具**：没有总分、没有等级、没有排名，`review.html` 也只显示「已核对 x / 6」。
2. **不是碳计算器**：四条读数是**教学映射的 0–100 相对刻度**，不是 kgCO₂e、不是营养素含量、不是港币。
3. **不是港式生活百科**：香港几乎不产食材，题目里所有「本地」都按「邻近产区当季」处理。
